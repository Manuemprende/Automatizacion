# Barbería Moderna

Este proyecto es una aplicación web sencilla para gestionar citas de una barbería.
Puedes agendar clientes, anular citas y consultar los tipos de cortes disponibles
con sus precios. Todo se almacena en el navegador mediante **localStorage**.
El diseño aprovecha **Bootstrap 5** y la fuente *Poppins* para un estilo moderno.

## Requisitos
Solo se necesita Python 3 para ejecutar el servidor local.

## Uso
1. Ejecuta `python server.py`.
2. Se abrirá automáticamente el navegador en `http://localhost:8000/index.html`.
3. Desde la página podrás agregar citas, ver el calendario y anular reservas.

Las citas y configuraciones se guardan en tu navegador, por lo que no
se requiere una base de datos adicional.
